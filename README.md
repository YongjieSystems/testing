# 永捷系統科技 檢測費估價程式

純前端工具，提供檢測報價、原廠保固與驅動下載入口。不需要 Gemini 或其他 API 金鑰。

## 開發與驗證

需要 Node.js 22 或更新版本，以及 pnpm（亦可使用 npm）。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

GitHub Pages 可直接提供根目錄的 index.html、app.js、quote-core.js；若使用建置部署，發布 dist/ 內容。Vite 的相對 base 支援 /testing/ 子路徑。

## 程式結構

- index.html：畫面、列印樣式。
- app.js：價格設定、表單互動、報價摘要與歷史紀錄。
- quote-core.js：金額驗證、總額計算、歷史資料讀取、HTML 編碼。
- quote-core.test.js：核心規則回歸測試。

## 使用與資料限制

- 金額使用整數新臺幣，範圍 0–1,000,000；負數歸零、小數捨去，超出範圍限制為上限。
- 可直接保存報價；複製成功或列印前也會保存，本機最多保留 200 筆。修改已存報價會另建單號並保留前版關聯；最多保留最近 200 筆。
- 建立新報價會重設表單並產生新單號，保留報價人員與部門。
- 新存歷史包含當時價格，未來調價不會改動該筆明細。舊版歷史沒有價格快照，無法還原當時價目；只能使用目前設定。
- 歷史僅存在該瀏覽器的 localStorage，沒有跨電腦同步或集中備份。清除網站資料會移除歷史。
- 保固狀態目前僅記錄資訊，不改變價格；主管減免仍需公司另行核准，本工具不具登入與核准權限控管。
- Tailwind CDN 與 Google Fonts 需要網路。後續可改成本地建置 CSS，改善離線可用性。

## v1.1 工作流程

1. 填客戶稱呼、型號、處理狀態與服務內容。
2. 使用「保存報價」保留可搜尋的紀錄；「保存草稿」保留一份尚未完成的表單。
3. 歷史可用單號、客戶、型號、故障備註、人員與狀態篩選。
4. 使用「匯出備份」下載 JSON；在另一台裝置匯入即可搬移資料。同單號以本機資料為準，超過 200 筆會拒絕匯入。
5. 手機底部有即時總額、「看明細」與「保存報價」。

備份包含客戶稱呼與報價內容，請妥善保存。JSON 備份最多 2 MB；匯入會驗證格式、價格快照與總額。原始資料備援供異常資料救援使用，與一般可匯入的備份格式不同。

此版本沒有跨裝置即時同步、主管登入核准或自動定期備份；清除網站資料仍可能移除本機紀錄。

## v1.2.0 收送估價第一階段

- 新報價採 schemaVersion 2；舊版資料與價格快照維持原規則。
- 三種方式為門市檢測、到府檢測及客製化收送服務。門市由客戶自行送件，不收收送費，檢測費照舊；到府保留原區域出勤費；只有客製化收送顯示順路排線、專程、優先、外包方案與成本分析。客製化費用人工確認，含約定取件回送，未核定不預設免費。切換方式保留成本輸入，但不套用於門市或一般到府；歷史與團隊資料仍沿用原服務代碼及價格快照。
- 排線須確認可執行路線與取件／回送時段。未齊資料只顯示目前小計；不能保存為客戶同意或已完成。
- 檢修優先／假日費不包含優先收送，也不保證當日修復。舊有價目金額未調高。
- 維修階段以維修金額取代檢測費及購於永捷檢測折抵。已付款只是人工記錄，不連接金流。
- 收送成本試算要求完整週期工時、每小時分攤成本、交通、其他成本及目標毛利；空白代表未知。所有金額須同一稅基。此為估計成本分攤，非淨利，也不等同外包節省現金。
- 成本欄位保存在本機報價及備份，不會寫入客戶摘要或列印。沒有主管權限、中央排線或跨裝置同步，公開網站無法提供真正的角色權限。
- 修改收送價格、方案或時段會取消費用確認；改方案或時段也取消排線確認。修改維修金額會取消維修確認。
- 修改已存報價另建單號，原版仍受最近 200 筆容量上限約束，請定期匯出備份。


## v1.3.0 結案成本回饋

- 加入實際人員總分鐘、其中工程師分鐘、實際平均分攤時薪、交通／物流、其他成本、實際收送淨收入與差異原因。工程師分鐘為總工時的子集合，不重複計費；收入應扣除分攤折扣／退款並排除維修收入。合併路線先分攤，不能每案重複填整趟成本。
- 完整填寫後勾選核對，才會將數值視為已核對。輸入未知、非法值或工程師時間超過總時間時，不判定為已核對。
- 歷史區增加內部成效表：各方案核對案數、收入減分攤成本、工程師時間及成本低估／可比案數。只計已完成且核對完整的案件，待核對及未完成另列；全為本機最近保留資料，不是公司全量或每月報表。
- caseId 與前版關聯共同辨識案件；依本機歷史順序取最新保存版本，修改、分支、重新開案及取消都不重複計入。匯入仍遵循本機同單號優先，不自動推定雲端最新版本；跨電腦資料合併後須核對版本。
- 成本比較使用本版的預估成本，缺少預估則標記不可比較；沒有營收時毛利率不計算，不以 0% 混淆。所有成本結果不代表整案淨利或節省現金。
- 取件回送增加明確時段確認勾選。舊 v1.2.0 收送報價金額不變，但缺少確認標記時需補勾並重新確認，不能只憑文字非空就視為排程已同意。
- 修改實際欄位、差異備註、收送方案或收送金額會取消實際核對。實際資料及統計不寫入客戶摘要或列印，僅進本機儲存與備份；保存報價才能納入成效表。

三套估價使用同一組已開通的員工帳號，各網站分別登入。估價僅主管及客服／行政可用；保固與驅動查詢保持公開。維修共用密碼入口已取消，助理口頭確認後可直接輸出客戶報價，團隊正式版、折抵及排線仍沿用原核准規則。

### 登入保存方式
登入頁可選「保持登入 24 小時」（預設）、「記住這台電腦 30 天」或「共用電腦／僅本次登入（目前分頁）」。24 小時與 30 天從登入成功起固定計算，重新開啟網頁會恢復登入，憑證自動更新不延長期限。僅本次登入不將憑證保存至 localStorage；重新整理可保留，關閉分頁後一般需重新登入（瀏覽器還原分頁可能保留分頁儲存）。個人專用電腦才使用 30 天。按「登出／清除記住登入」會清除此程式在本瀏覽器的保存，原有報價備份不變。清除網站資料、無痕模式、後端撤銷憑證或停用員工也可能要求重登。

三套程式各自保存期限及登入選擇，不將密碼寫入程式，也不將登入憑證加入報價備份。舊版分頁登入只遷移為本次登入；必須由員工下次登入時自行選擇較長期限。期限屬於瀏覽器保存政策，Supabase 驗證、啟用員工檢查及資料庫權限照常執行，未修改後端 JWT 有效期。到期時立即關閉估價與共用資料入口並清除保存憑證，未保存的報價內容仍需員工自行保存。


### 指定工程師的助理作業權限
工程師會員資料可由系統管理者另外開通 `staff_access`。`role` 保持 ENGINEER，仍可分派工程師任務；有效作業權限比照 STAFF，能估價、預覽、複製／列印、讀取同團隊共用案件及同步版本。主管核准、員工管理、主管私有成本及發布路線仍不開放。此旗標只能由受信任的後端管理作業設定，員工不能自行修改；未開通的工程師、收送人員及其他團隊權限維持原狀。帳號停用後即失去上述權限。

此次僅開通永捷系統科技團隊的 engineer@service5c.com.tw；檢測、維修與租賃讀取同一份會員權限。畫面顯示「工程師（助理同等作業權限）」。資料庫變更來源為 `supabase/engineer_staff_access.sql`。
