# 驅動入口對照（2026-10-18）

保固清單 25 家逐家對照，新增為 15 家一般驅動入口、1 家特殊平台下載指引。網址與各家操作提示保存在 `driver-data.js`，品牌名稱與保固清單共用，避免兩邊名稱不一致。

一般入口：捷元、Lenovo、ViewSonic、BenQ、GIGABYTE、Philips、AOC、Acer、ASUS、Brother、Canon、Dell、Epson、HP、MSI。

Apple 為 [Intel Mac 的 Windows 支援軟體官方下載指引](https://support.apple.com/zh-tw/102465)，須由啟動切換輔助程式取得對應機型驅動，不是通用安裝檔，也不適用 Apple 晶片 Mac。

沒有把儲存管理工具當成驅動：[ADATA SSD Toolbox](https://www.adata.com/tw/support/downloads/)、[Kingston SSD Manager](https://www.kingston.com/tw/support/technical/ssdmanager/)、[Seagate 工具](https://www.seagate.com/tw/zh/support/downloads/)、[WD 軟體](https://support-en.wd.com/app/products/downloads/softwaredownloads) 及 [創見產品支援](https://transcend.com.tw/support/service) 暫不列入。Toshiba 對應硬碟，不能以同名印表機或舊筆電驅動替代。

展碁、建達、精技為代理／通路，未確認可用的通用驅動選型頁，因此不新增；精技與精聯電子 unitech 不可混淆。[展碁檔案區](https://www.weblink.com.tw/en/download.htm) 沒有取得可用的通用驅動選型證據。

確認方式：一般入口用原廠頁面／官方搜尋內容核對用途；HP、Brother 與 Lenovo 另以實際瀏覽器確認產品選擇或搜尋入口。搜尋擷取 HP 與 Brother 曾遭 403，但瀏覽器正常顯示原廠下載頁。Lenovo 採已能開啟的總支援站，需再選產品；子站可能受原廠暫時故障影響。Dell 可能依地區轉址，須切回台灣。Philips 需先搜尋型號，再開產品的軟體／驅動欄。

這次沒有下載、執行安裝檔或使用客戶序號；入口可用不代表任意機型／作業系統均有驅動。搜尋只搜尋此站品牌與類別，型號需至原廠輸入。所有外部下載連結均為 HTTPS、新分頁開啟並設定 noopener noreferrer。
